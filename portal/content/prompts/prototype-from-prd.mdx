Use this prompt with [Claude Code](/tools/claude-code) to build working starter code from a finished PRD. The same running version serves as the interactive prototype for the next Measure round.

## Tips

- The step where Claude Code confirms with you before writing any code is what stops it generating 500 lines of code you do not need. Do not skip it.
- The output is reference code, not production code. Treat it as the starting point for the team's iterations, and let the engineering side (DevSecOps) act on it in parallel.
- If Claude Code starts inventing PRIZM components that do not exist, stop it and tell it to check `lib/components-registry.ts` in the PRIZM repository (its code store on GitHub) before generating.
- The prototype is what the next Measure phase puts in front of users. Pair it with the [test-plan generator](/prompts/test-plan-generator), which reads the PRD to draft the plan. Then close the loop with usability sessions and DASH surveys.
