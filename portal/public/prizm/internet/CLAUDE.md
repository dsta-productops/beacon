# PRIZM
This project uses PRIZM, at https://github.com/prizm-design/prizm.
- Before building any screen, read https://raw.githubusercontent.com/prizm-design/prizm/main/PRIZM.md and https://raw.githubusercontent.com/prizm-design/prizm/main/llms.txt.
- Fetch components from that repository as PRIZM.md describes. Do not invent components.
- Use semantic colour tokens such as bg-bg and text-fg, never raw colours.
- Build the prototype in a new folder called prototype, not at the top of this folder.
