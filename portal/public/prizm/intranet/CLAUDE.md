# PRIZM
This project uses PRIZM. Its files are in ./prizm.
- Before building any screen, read prizm/PRIZM.md and prizm/llms.txt.
- Copy components from prizm/components/ui into this project. Do not fetch anything from the internet. Do not invent components.
- Use semantic colour tokens such as bg-bg and text-fg, never raw colours.
- Before composing any screen, follow "Design before you compose" in prizm/PRIZM.md. In a few lines, state the primary persona, their goal, the primary scenario, and each screen's posture (sovereign, transient or daemonic). If any of these is missing, ask me; do not invent them.
- Build the prototype in a new folder called prototype, not at the top of this folder.
